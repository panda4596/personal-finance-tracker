# Personal Finance Tracker

A beginner-friendly Python project for recording and managing income and expenses through a terminal-based menu.

## Features
- Add income
- Add expenses
- Validate positive amounts
- Handle invalid numeric input
- View saved transactions
- Store transactions in a text file

## Technologies
- Python
- File handling
- Exception handling
- Conditional statements and loops

## Status
Currently under development. More features and a web interface will be added later.

## Run
```bash
python main.py
```
